## แสดงผลลัพธ์ทางจอภาพ
### ภาษา C
```c
#include <stdio.h>
#include <stdlib.h>
int main(void){
    printf("\n\nHello, World!\n");
    printf("Welcome to Data Structures and Algorithms in C\C++\n\n");
    /*
     * 1.ให้นักศึกษาเขียนโปรแกรมแสดงข้อความ ดังนี้
     * รหัสนักศึกษา ชื่อ-นามสุกล อายุ เพศ ชั้นปี มหาวิทยาลัย คณะ 
     * สาขาวิชา เกรดเฉลี่ย 
     * แสดงผลลัพธ์ออกทางจอภาพ
     * โดยใช้คำสั่ง printf() ในการแสดงผลลัพธ์
     */
    return 0;   
}
```
