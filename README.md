# เรื่อง โครงสร้างข้อมูลและอัลกอริทึม
เป็นการนำขั้นตอนวิธีทางคอมพิวเตอร์มาใช้ในการจัดการข้อมูล จัดการงานต่างๆ จัดการกระบวนการทำงาน คำนวณทางคณิตศาสตร์ เพื่อให้มีประสิทธิภาพและประหยัดทรัพยากรในการทำงาน โดยใช้เน้นกระบวนการทางคอมพิวเตอร์ หรือการเขียนโปรแกรม การจัดดโครงสร้างข้อมูล อันได้แก่ ประหยัดเวลา ลดการทำงานที่ซ้ำซ้อน และงานที่มีขนาดใหญ่มาก  เพิ่มความสะดวกสำหรับการทำงาน ในชีวิตประจำวัน

1. พื้นฐาน แนวคิด และทฤษฏีของโครงสร้างข้อมูล และอัลกอริทึม
2. ปัญหาและวิธีการแก้ปัญหา
3. เครื่องมือการแก้ปัญหา
4. ขั้นตอนวิธี อัลกอริทึม รหัสเทียม ผังงาน และการเขียนโปรแกรม
5. ชนิดช้อมูล
6. การดำเนินการทางคณิตศาสตร์ บวก ลบ คูณ หาร 
7. การวนซ้ำ และการตรวจสอบเงื่อนไข
